# Утилита для подсчета строк кода в папке проекта

## О программе
* Данная утилита проста в использовании
* Содержит понятный исходный код

# Функционал
* Подсчет строк кода в папке
* Определение языка программирования кода

## На чем написано
* Язык Python, ВМ CPython 3.14.7
* Библиотеки libpath, tkinter, customtkinter, os
